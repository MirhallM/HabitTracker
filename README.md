# Habit Tracker

Aplicación web para crear, organizar y dar seguimiento a hábitos personales — proyecto final del curso de Experiencia de Usuario (UNITEC).

## Stack

- **Frontend:** Next.js (App Router) + Material UI
- **Backend:** NestJS
- **Base de datos:** MongoDB (Mongoose)
- **Auth:** JWT

## Estructura del repositorio

```
HabitTracker/
├── frontend/     # Next.js + MUI
├── backend/      # NestJS API
└── CLAUDE.md     # Contexto del proyecto para Claude Code
```

## Estado del proyecto

- [x] Avance 1 — Investigación, UX, sistema de diseño, wireframes, documento preliminar de API
- [ ] Avance 2 — CRUD funcional conectado a MongoDB, autenticación
- [ ] Avance 3 — Dashboard, estadísticas, pulido y pruebas de usabilidad

## Cómo correr el proyecto

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
npm install
npm run start:dev
```
